LLaMA Fine-tuning

70B model with 3D parallelism

Fine-tune LLaMA 70B on custom instruction data using tensor parallel, pipeline parallel, and ZeRO-3.

FSDP TP=8 BF16 
# train_llama.py
from distributed_ml import DistributedTrainer
from transformers import LlamaForCausalLM

model = LlamaForCausalLM.from_pretrained(
    "meta-llama/Llama-2-70b-hf",
    torch_dtype=torch.bfloat16
)

trainer = DistributedTrainer(
    model=model,
    tensor_parallel_size=8,
    pipeline_parallel_size=4,
    zero_stage=3,
    gradient_checkpointing=True,
    learning_rate=2e-5,
    per_device_batch_size=1,
    gradient_accumulation_steps=8
)

ViT-G Pre-training

2B parameter vision transformer

Pre-train a giant Vision Transformer on ImageNet-21K with data parallelism and automatic mixed precision.

DDP AMP Gradient Clipping 
# train_vit.py
import torch.distributed as dist
from timm.models import create_model

model = create_model('vit_giant_patch14_224')
model = torch.nn.parallel.DistributedDataParallel(
    model.cuda(),
    device_ids=[dist.get_rank()]
)

scaler = torch.cuda.amp.GradScaler()

for images, labels in dataloader:
    with torch.cuda.amp.autocast(dtype=torch.bfloat16):
        loss = model(images, labels)

    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()

Stable Diffusion Training

Text-to-image generation

Train a latent diffusion model with EMA, CFG, and multi-resolution training.

FSDP EMA xFormers 
# train_diffusion.py
from diffusers import UNet2DConditionModel
from distributed_ml import wrap_fsdp, FSDPConfig

unet = UNet2DConditionModel.from_pretrained(
    "stabilityai/stable-diffusion-xl-base-1.0",
    subfolder="unet"
)

unet = wrap_fsdp(unet, FSDPConfig(
    sharding_strategy="FULL_SHARD",
    mixed_precision="bf16",
    activation_checkpointing=True
))

# EMA model on CPU
ema = EMAModel(unet.parameters(), decay=0.9999)

Whisper Fine-tuning

Speech recognition

Fine-tune Whisper Large-v3 on domain-specific audio data with LoRA and gradient checkpointing.

LoRA DDP Flash Attn 
# train_whisper.py
from transformers import WhisperForConditionalGeneration
from peft import LoraConfig, get_peft_model

model = WhisperForConditionalGeneration.from_pretrained(
    "openai/whisper-large-v3",
    use_flash_attention_2=True
)

lora_config = LoraConfig(
    r=32, lora_alpha=64,
    target_modules=["q_proj", "v_proj"]
)
model = get_peft_model(model, lora_config)

# Enable gradient checkpointing
model.gradient_checkpointing_enable()

Quick Start Scripts

Single Node Multi-GPU

# Launch with torchrun
torchrun --nproc_per_node=8 \
    train.py \
    --batch_size 32 \
    --gradient_accumulation 4 \
    --mixed_precision bf16

# Or with accelerate
accelerate launch --multi_gpu \
    --num_processes 8 \
    train.py

Multi-Node Cluster

# SLURM job submission
srun --nodes=4 --ntasks-per-node=8 \
    --gpus-per-node=8 \
    torchrun \
    --nnodes=$SLURM_NNODES \
    --nproc_per_node=8 \
    --rdzv_backend=c10d \
    --rdzv_endpoint=$MASTER_ADDR:29500 \
    train.py

DeepSpeed Launch

# With hostfile
deepspeed --hostfile hostfile.txt \
    --num_gpus 8 \
    train.py \
    --deepspeed ds_config.json

# With SLURM
deepspeed --launcher slurm \
    train.py --deepspeed
