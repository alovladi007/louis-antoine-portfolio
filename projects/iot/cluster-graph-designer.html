Design and visualize continuous-variable cluster state graphs with customizable topologies and adjacency matrices

Graph State Definition

A CV cluster state is defined by its adjacency matrix A, where Ajk specifies the CZ gate weight between modes j and k. The nullifier operators are:

δj = pj - Σk Ajk xk

Ideal cluster: ⟨δj²⟩ → 0 for infinite squeezing

Common Topologies:

  • Linear: 1D chain for single-rail encoding
  • Square: 2D lattice for surface codes
  • Hexagonal: Optimal for certain MBQC tasks
  • GHZ-Rail: Dual-rail for fault tolerance
