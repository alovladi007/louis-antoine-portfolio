FDTD Method

The Finite-Difference Time-Domain method solves Maxwell's equations in the time domain:

Maxwell's Equations

The FDTD method discretizes Maxwell's equations:

$$\nabla \times \vec{E} = -\mu \frac{\partial \vec{H}}{\partial t}$$

$$\nabla \times \vec{H} = \epsilon \frac{\partial \vec{E}}{\partial t} + \vec{J}$$

Yee Algorithm

The Yee algorithm uses a staggered grid with electric and magnetic fields:

$$E_x^{n+1}(i,j,k) = E_x^n(i,j,k) + \frac{\Delta t}{\epsilon} \left[\frac{H_z^{n+1/2}(i,j+1,k) - H_z^{n+1/2}(i,j,k)}{\Delta y} - \frac{H_y^{n+1/2}(i,j,k+1) - H_y^{n+1/2}(i,j,k)}{\Delta z}\right]$$

Stability Condition

The Courant-Friedrichs-Lewy (CFL) stability condition:

$$\Delta t \leq \frac{1}{c\sqrt{\frac{1}{(\Delta x)^2} + \frac{1}{(\Delta y)^2} + \frac{1}{(\Delta z)^2}}}$$
