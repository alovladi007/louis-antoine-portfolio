Neural Decoding Theory

Neuroscience fundamentals and decoding algorithms

Neural Signal Basics

Action Potentials

Neurons communicate via action potentials (spikes), brief electrical impulses lasting ~1ms with amplitudes of 50-500 µV when recorded extracellularly.

Single-Unit Activity (SUA)
Spikes from individual neurons, isolated through spike sorting
Multi-Unit Activity (MUA)
Combined activity from multiple nearby neurons
Local Field Potential (LFP)
Low-frequency (<300 Hz) synaptic activity
ECoG / EEG
Surface or scalp recordings of population activity

Motor Cortex Organization

Primary motor cortex (M1) and premotor areas contain neurons that encode movement parameters:

  • Movement direction: Cosine tuning to preferred direction
  • Velocity: Firing rate modulated by movement speed
  • Position: Some neurons encode target or hand position
  • Force: Activity correlates with grip force and torque

Spike Sorting

Detection

Spikes are detected when the signal crosses a threshold, typically set at 4-5 standard deviations of the noise:

Threshold = µ ± k × σ_noise

where σ_noise = median(|x|) / 0.6745  (robust estimator)
      k = 4-5 (detection threshold)

Feature Extraction

Principal Component Analysis:
X_centered = X - µ
Σ = (1/n) X_centered^T × X_centered
V = eigenvectors(Σ)
Features = X_centered × V[:, 1:k]  (first k components)

Wavelet Features:
W = DWT(spike, 'db4')
Select coefficients with highest variance

Clustering

Gaussian Mixture Model:
p(x) = Σ πk × N(x | µk, Σk)

Log-likelihood:
L = Σ log(Σ πk × N(xi | µk, Σk))

Maximize via EM algorithm:
E-step: γik = πk × N(xi | µk, Σk) / p(xi)
M-step: µk = Σ γik × xi / Σ γik

Quality Metrics

Isolation Distance
Mahalanobis distance to nearest cluster
L-Ratio
Contamination from other clusters
ISI Violations
Spikes within refractory period (<1ms)
SNR
Peak amplitude / noise standard deviation

Directional Tuning

Cosine Tuning Model

Motor cortex neurons exhibit cosine tuning to movement direction:

f(θ) = b + m × cos(θ - θ_pd)

where:
  f(θ) = firing rate at direction θ
  b = baseline firing rate
  m = modulation depth
  θ_pd = preferred direction

Fit via linear regression:
f = b + c₁cos(θ) + c₂sin(θ)
θ_pd = atan2(c₂, c₁)
m = √(c₁² + c₂²)

Population Vector Algorithm

Population vector P:
P = Σ wᵢ × (fᵢ - bᵢ) × dᵢ

where:
  wᵢ = weight for neuron i (often 1)
  fᵢ = observed firing rate
  bᵢ = baseline rate
  dᵢ = unit vector in preferred direction

Decoded direction = atan2(Py, Px)

Decoding Algorithms

Kalman Filter

Optimal linear estimator for state-space models:

State equation:
  x_t = A × x_{t-1} + w   (w ~ N(0, W))

Observation equation:
  y_t = H × x_t + q       (q ~ N(0, Q))

Prediction:
  x̂_t|t-1 = A × x̂_{t-1}
  P_t|t-1 = A × P_{t-1} × A^T + W

Update:
  K_t = P_t|t-1 × H^T × (H × P_t|t-1 × H^T + Q)^{-1}
  x̂_t = x̂_t|t-1 + K_t × (y_t - H × x̂_t|t-1)
  P_t = (I - K_t × H) × P_t|t-1

Wiener Filter

Linear decoder with spike history:
x_t = Σ W_τ × y_{t-τ}  for τ = 0 to L (lags)

Optimal weights (least squares):
W = (Y^T × Y)^{-1} × Y^T × X

where Y is the lagged spike rate matrix

ReFIT Kalman

Intention-estimation Kalman filter with velocity-based feedback:

During closed-loop:
1. Decode intended velocity v̂
2. Compare to cursor velocity v_cursor
3. Update: v_new = α × v̂ + (1-α) × v_cursor

Recalibration uses intention estimates
rather than actual cursor movements

Real-Time Considerations

Latency Budget

  • • Acquisition: ~1 ms
  • • Filtering: ~0.1 ms
  • • Spike detection: ~0.05 ms
  • • Binning/sorting: ~0.1 ms
  • • Decoding: ~0.2 ms
  • • Output: ~0.5 ms
  • Total: <2 ms target

Causal Filtering

Real-time systems require causal filters (no future samples). Use IIR filters with forward-only processing instead of zero-phase filtfilt.

Buffer Management

Circular buffers prevent memory allocation. Double-buffering allows processing while acquiring new data.

Decoder Stability

Neural signals drift over time. Adaptive decoders (e.g., ReFIT) maintain performance without manual recalibration.
