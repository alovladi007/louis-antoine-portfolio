Input Modalities

System Architecture

Vision Encoder

  • CLIP ViT-L/14 with 428M parameters
  • 224×224 to 336×336 input resolution
  • 768-dim visual embeddings
  • Contrastive pre-training on 400M pairs

Text Encoder

  • CLIP Text Transformer (12 layers)
  • 77 token context length
  • BPE tokenization (49K vocab)
  • Joint vision-language embedding space

Audio Encoder

  • Whisper Large-v3 (1.55B params)
  • 30-second audio chunks
  • Multilingual support (99 languages)
  • Automatic language detection
