Project Overview

This project develops state-of-the-art generative models for scientific data, enabling accelerated discovery in drug design, materials science, and physics simulation. We leverage diffusion models, variational autoencoders, and flow-based architectures.

Key innovations include physics-informed latent spaces, equivariant neural network architectures for 3D molecular generation, and conditional generation with property optimization.

Key Features

  • 3D molecular generation with SE(3) equivariance
  • Physics-constrained latent diffusion
  • Property-guided conditional generation
  • Multi-scale materials modeling
  • Uncertainty quantification
