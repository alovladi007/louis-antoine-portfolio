Multimodal Learning Theory

Foundations of vision-language-audio AI systems

Contrastive Learning

CLIP (Contrastive Language-Image Pre-training) learns joint vision-language representations by maximizing similarity between matched image-text pairs while minimizing similarity for non-matched pairs.

$$\mathcal{L}_{CLIP} = -\frac{1}{N}\sum_{i=1}^{N}\left[\log\frac{\exp(s_{i,i}/\tau)}{\sum_{j=1}^{N}\exp(s_{i,j}/\tau)}\right]$$

where \(s_{i,j} = f_I(x_i) \cdot f_T(y_j)\) is the cosine similarity and \(\tau\) is temperature

Image Encoder \(f_I\)

Vision Transformer (ViT) that processes images as sequences of patches, producing a global [CLS] representation.

Text Encoder \(f_T\)

Transformer encoder that processes tokenized text, using the [EOS] token representation as the text embedding.

Vision Transformer (ViT)

ViT treats images as sequences of patches, applying the transformer architecture directly to visual data.

$$\mathbf{z}_0 = [\mathbf{x}_{class}; \mathbf{x}_p^1\mathbf{E}; \mathbf{x}_p^2\mathbf{E}; \cdots; \mathbf{x}_p^N\mathbf{E}] + \mathbf{E}_{pos}$$

Patch embedding with learnable position encodings

  • Patch Size: Typically 14×14 or 16×16 pixels
  • Sequence Length: (H/P) × (W/P) + 1 (with [CLS] token)
  • Self-Attention: Global receptive field from first layer
  • Pre-training: Often with masked image modeling or contrastive learning

Whisper Architecture

Whisper is an encoder-decoder transformer trained on 680,000 hours of multilingual and multitask supervised data from the web.

Audio Preprocessing

Audio is resampled to 16kHz, converted to 80-channel log-mel spectrogram using 25ms windows with 10ms stride.

Encoder

Two 1D convolutions with GELU activation, followed by transformer layers with sinusoidal position embeddings.

Decoder

Autoregressive transformer with cross-attention to encoder outputs, trained with special tokens for tasks (transcribe, translate, timestamps).

Multimodal Fusion

Combining information from multiple modalities can be done at different stages of the processing pipeline.

Early Fusion

Concatenate raw inputs or early features before joint processing. Simple but may lose modality-specific information.

Late Fusion

Process each modality independently, combine final representations. Preserves modality-specific features.

Cross-Attention

Use attention mechanisms to allow modalities to attend to each other. Most flexible but computationally expensive.

$$\text{CrossAttn}(Q_v, K_t, V_t) = \text{softmax}\left(\frac{Q_v K_t^T}{\sqrt{d_k}}\right)V_t$$

Vision queries attending to text keys and values

Zero-Shot Classification

CLIP enables zero-shot classification by comparing image embeddings with text embeddings of class descriptions.

$$p(y|x) = \frac{\exp(f_I(x) \cdot f_T(t_y)/\tau)}{\sum_{y'}\exp(f_I(x) \cdot f_T(t_{y'})/\tau)}$$

where \(t_y\) is the text prompt for class \(y\), e.g., "a photo of a {class}"

  • Prompt Engineering: "a photo of a {class}" often outperforms just "{class}"
  • Ensemble Prompts: Average over multiple prompts for better accuracy
  • Temperature: Lower τ sharpens predictions, higher τ smooths them

Embedding Spaces

Multimodal models learn to project different modalities into a shared embedding space where semantic similarity is preserved.

$$\text{sim}(u, v) = \frac{u \cdot v}{\|u\| \|v\|} = \cos(\theta)$$

Cosine similarity in embedding space

Properties

  • • Unit-normalized embeddings
  • • Semantic similarity = geometric proximity
  • • Cross-modal alignment

Applications

  • • Image-text retrieval
  • • Zero-shot classification
  • • Semantic search

Evaluation Metrics

Recall@K

Fraction of queries where the correct result appears in the top K retrieved items.

Word Error Rate (WER)

$$WER = \frac{S + D + I}{N}$$ where S, D, I are substitutions, deletions, insertions.

Zero-Shot Accuracy

Classification accuracy on classes not seen during training, using text descriptions as classifiers.
