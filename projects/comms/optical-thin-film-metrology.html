Optical Thin-Film Metrology System

Python-based reflectometry tool demonstrating spectral interference analysis for thin-film thickness extraction. Built to showcase optical metrology techniques to lab advisor.

Research Overview

During my research in optical thin-film metrology, I built a comprehensive Python-based reflectometry tool to demonstrate how film thickness could be extracted from spectral interference data — essentially a simplified version of the algorithms used in commercial systems like KLA SpectraFilm.

I interfaced a spectrometer with a motorized XY stage, wrote the acquisition and fitting code from scratch, and visualized real-time thickness maps to demonstrate feasibility to my lab advisor.

~1,860 Lines of Python Code
5 Core Modules
6 API Endpoints
Sub-nanometer Precision

Key Features

Transfer Matrix Method

Full implementation of the 2×2 transfer matrix formalism for calculating reflection and transmission in multi-layer thin-film stacks. Handles complex refractive indices and interference effects.

  • Fresnel coefficients at each interface
  • Phase accumulation in layers
  • Support for absorbing films (complex n̂ = n + ik)
  • Material library with Cauchy & Sellmeier dispersion

Spectral Reflectometry

FFT-based analysis of interference fringes in reflectance spectra to extract optical thickness. Includes noise filtering and envelope detection methods.

  • FFT power spectrum analysis
  • Envelope method for fringe counting
  • Peak detection and spacing analysis
  • Signal detrending and windowing

Advanced Fitting Algorithms

Multiple optimization algorithms for robust thickness extraction from measured spectra with uncertainty quantification.

  • Levenberg-Marquardt (local, fast)
  • Differential Evolution (global, robust)
  • Two-stage hybrid optimization
  • Uncertainty from Jacobian analysis

Motorized Stage Control

Simulated XY stage control with multiple scan patterns for spatial mapping of film thickness across wafers.

  • Raster, snake, spiral, random patterns
  • Position feedback and error modeling
  • Scan time optimization
  • Real-time acquisition simulation

2D/3D Thickness Mapping

Real-time visualization of spatial thickness variations with statistical overlays and publication-quality plots.

  • 2D heatmaps with statistics
  • 3D surface plots
  • Uniformity metrics (mean, σ, range)
  • Live updating during scans

Material Library

Comprehensive database of optical materials with wavelength-dependent refractive indices.

  • SiO₂, Si₃N₄, TiO₂, Al₂O₃, Ta₂O₅, HfO₂
  • Cauchy dispersion formula
  • Sellmeier formula support
  • Custom material definitions

Physics: Transfer Matrix Formalism

Each thin-film system is represented by a product of 2×2 matrices:

Mtotal = I0 · P1 · I1 · P2 · I2 · ... · In

Where:

  • I = Interface matrix: Fresnel reflection/transmission coefficients
  • P = Propagation matrix: Phase accumulation through layer (β = 2πnd/λ)
  • Reflectance: R = |M21/M11|²
