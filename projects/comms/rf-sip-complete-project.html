Project Overview

This project implements a complete RF/High-Speed System-in-Package (SiP) co-design platform for next-generation wireless and wireline communication systems. The platform integrates electromagnetic simulation, signal integrity analysis, and package-level thermal management.

Key innovations include a novel mmWave antenna-in-package (AiP) design methodology, 3D electromagnetic co-simulation workflow, and automated impedance matching network synthesis.

Key Features

  • 28 GHz phased array antenna-in-package
  • 112 Gbps PAM4 SerDes signal integrity
  • 3D EM co-simulation with HFSS/ADS
  • Thermal-aware power distribution network
  • Automated design rule checking
