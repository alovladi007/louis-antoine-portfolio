Tutorial 1: Setting Up OFDM Acoustic Link

1 Initialize Modem

const modem = new AcousticModem({ subcarriers: 64, bandwidth: 12000, centerFreq: 24000 });

2 Configure Modulation

modem.setModulation('QPSK'); modem.setFEC('ReedSolomon', {n: 255, k: 223});

3 Transmit Data

const data = new Uint8Array([0x48, 0x65, 0x6c, 0x6c, 0x6f]); // "Hello" modem.transmit(data);

Tutorial 2: Optical Link Alignment

1 Configure LED Array

const optical = new OpticalLink({ wavelength: 520, // nm (green) power: 1.0, // W beamAngle: 20 // degrees });

2 Acquire Link

optical.scan(); if (optical.isAligned()) { optical.startTransmission(); }
