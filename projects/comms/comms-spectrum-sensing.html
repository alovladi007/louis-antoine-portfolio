Detection Method Comparison

Energy Detection

  • + Simple implementation
  • + No prior signal knowledge
  • - Poor in low SNR
  • - Noise uncertainty

Cyclostationary

  • + Noise robust
  • + Signal classification
  • - High complexity
  • - Longer sensing time

Matched Filter

  • + Optimal detection
  • + Short sensing time
  • - Requires pilot/preamble
  • - Dedicated receiver

Covariance

  • + No noise floor needed
  • + Multi-antenna benefit
  • - Moderate complexity
  • - Sample dependent
