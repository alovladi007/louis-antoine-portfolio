Acoustic Modem API

initOFDM()

Initialize OFDM modem with subcarrier configuration.

initOFDM(numSubcarriers: number, bandwidth: number): Modem // Example: const modem = initOFDM(64, 12000); // 64 subcarriers, 12 kHz bandwidth

transmit()

Modulate and transmit data packet.

transmit(data: Uint8Array, modulation: string): void modem.transmit(dataPacket, 'QPSK');
