Link Budget Equations Reference

Underwater Acoustic

  • TL = 20log(r) + αr
  • α = 0.11f²/(1+f²) + 44f²/(4100+f²)
  • NL = 50 + 20log(f) - 17log(D)
  • SNR = SL - TL - NL + DI

RF (Free Space)

  • FSPL = 20log(d) + 20log(f) + 20log(4π/c)
  • Pr = Pt + Gt + Gr - FSPL - L
  • Eb/N0 = C/N0 - 10log(Rb)
  • C = B·log₂(1 + SNR)
