Semantic Segmentation Loss

The lane segmentation model is trained using a combination of Cross-Entropy and Dice loss for optimal boundary delineation:

U-Net Architecture

Encoder Block 1Conv(3,64) + BatchNorm + ReLU + MaxPool2D
Encoder Block 2Conv(64,128) + BatchNorm + ReLU + MaxPool2D
Encoder Block 3Conv(128,256) + BatchNorm + ReLU + MaxPool2D
Encoder Block 4Conv(256,512) + BatchNorm + ReLU + MaxPool2D
BottleneckConv(512,1024) + BatchNorm + ReLU + Dropout(0.5)
Decoder Block 4UpConv(1024,512) + Skip Connection + Conv
Decoder Block 3UpConv(512,256) + Skip Connection + Conv
Decoder Block 2UpConv(256,128) + Skip Connection + Conv
Decoder Block 1UpConv(128,64) + Skip Connection + Conv
Output LayerConv(64, num_classes) + Softmax
