Understanding INS Error Propagation

Error State Dynamics

Inertial navigation errors grow due to the double integration of acceleration and integration of angular rate:

δẋ = F δx + G w

Where the error state vector contains:

δx = [δpT δvT δψT bgT baT]T

Why Errors Grow Quadratically

Accelerometer biases directly cause velocity errors through integration. These velocity errors then integrate again to cause position errors, resulting in quadratic growth:

δp(t) ≈ δp0 + δv0t + ½bat²

Typical IMU Classes

  • Consumer-grade: 10-100 deg/hr gyro bias, 1000+ μg accel bias (phone IMUs)
  • Tactical-grade: 0.1-10 deg/hr gyro bias, 10-100 μg accel bias (AUV navigation)
  • Navigation-grade: 0.001-0.1 deg/hr gyro bias, 1-10 μg accel bias (submarines)
  • Strategic-grade: < 0.001 deg/hr gyro bias, < 1 μg accel bias (ICBMs)
