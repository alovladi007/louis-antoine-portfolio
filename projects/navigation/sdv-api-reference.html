Object Detection

POST /api/v1/detection/detect

Perform real-time object detection on input image using YOLOv8

Request Body

ParameterTypeDescription
imagebase64 requiredBase64 encoded image
confidencefloatConfidence threshold (default: 0.5)
classesarrayFilter by class names

Response

{
  "detections": [
    {
      "class": "car",
      "confidence": 0.94,
      "bbox": [x1, y1, x2, y2],
      "track_id": 1
    }
  ],
  "inference_time_ms": 23.4,
  "image_size": [1920, 1080]
}

200 Success

400 Invalid image format

Lane Detection

POST /api/v1/lane/segment

Perform semantic segmentation for lane boundaries

ParameterTypeDescription
imagebase64 requiredBase64 encoded image
modelstringModel variant: "unet", "deeplabv3"

Response

{
  "lanes": [
    {"type": "left", "points": [[x1,y1], [x2,y2], ...]},
    {"type": "ego", "points": [[x1,y1], [x2,y2], ...]},
    {"type": "right", "points": [[x1,y1], [x2,y2], ...]}
  ],
  "ego_lane_confidence": 0.97,
  "curvature": 0.0023
}

Object Tracking

POST /api/v1/tracking/update

Update tracker with new detections

// Request
{
  "detections": [...],
  "frame_id": 142,
  "timestamp": 1699234567.123
}

// Response
{
  "tracks": [
    {
      "track_id": 1,
      "class": "car",
      "state": "confirmed",
      "bbox": [x1, y1, x2, y2],
      "velocity": [vx, vy],
      "age": 45
    }
  ]
}

Sensor Fusion

POST /api/v1/fusion/update

Fuse multi-sensor data using Extended Kalman Filter

// Request
{
  "camera_detections": [...],
  "lidar_points": [...],
  "radar_returns": [...],
  "timestamp": 1699234567.123
}

// Response
{
  "fused_objects": [
    {
      "id": 1,
      "position": [x, y, z],
      "velocity": [vx, vy, vz],
      "covariance": [[...]],
      "confidence": 0.98
    }
  ]
}

Collision Prediction

POST /api/v1/collision/predict

Predict collision risk based on trajectory forecasting

// Response
{
  "collision_risk": 0.12,
  "time_to_collision": 4.5,
  "critical_objects": [
    {
      "id": 3,
      "risk_level": "medium",
      "predicted_trajectory": [[x,y,t], ...]
    }
  ],
  "recommended_action": "maintain_speed"
}
