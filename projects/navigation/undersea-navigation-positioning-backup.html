Project Overview

This project implements a state-of-the-art navigation and positioning system for autonomous underwater vehicles operating in GPS-denied environments. By fusing multiple sensor modalities through advanced Kalman filtering techniques, the system achieves sub-meter positioning accuracy over extended missions.

Key Innovation

Multi-sensor fusion architecture combining:

  • INS/IMU: High-rate inertial measurements for dead reckoning
  • Doppler Velocity Log (DVL): Bottom-track velocity estimation
  • Acoustic Positioning: Long-baseline (LBL) / Ultra-short baseline (USBL)
  • Terrain-Aided Navigation: Bathymetric map matching for drift correction
  • Pressure Sensor: Precise depth measurement

Acoustic Positioning Systems

Long-baseline (LBL) and Ultra-short baseline (USBL) acoustic systems provide absolute position fixes to bound INS drift.

Terrain-Aided Navigation (TAN)

Matches real-time depth soundings to a priori bathymetric maps for passive, covert position estimation without external beacons.

TAN Algorithm

Process

  1. Map Preparation: Load high-resolution bathymetric database
  2. Depth Measurement: Continuous multi-beam sonar scanning
  3. Correlation: Match measured vs. predicted depth profiles
  4. Position Update: Correct INS drift based on best match
Parameter Value Notes
Map Resolution 5-50 m grid Depends on survey data quality
Depth Accuracy Required < 0.5 m High-precision pressure sensor
Terrain Variability > 10 m per km Minimum for reliable matching
Update Rate 0.1-1 Hz Computationally intensive
Position Accuracy 5-20 m CEP In moderate terrain

Extended Kalman Filter (EKF)

The navigation solution fuses all sensor inputs through an Extended Kalman Filter, optimally weighting each measurement based on its uncertainty.

State Vector (15-state EKF)

State Description Units
Position (x, y, z) 3D position in navigation frame meters
Velocity (vₓ, vᵧ, vᵤ) 3D velocity vector m/s
Attitude (φ, θ, ψ) Roll, pitch, yaw angles radians
Gyro Bias (bₓ, bᵧ, bᵤ) Gyroscope bias errors rad/s
Accel Bias (bₐₓ, bₐᵧ, bₐᵤ) Accelerometer bias errors m/s²

EKF Implementation

  • Prediction: Propagate state using IMU measurements (100 Hz)
  • DVL Update: Velocity correction (1-10 Hz)
  • Acoustic Update: Position correction (0.2-1 Hz)
  • TAN Update: Position refinement (0.1-1 Hz)
  • Depth Update: Altitude constraint (10 Hz)
