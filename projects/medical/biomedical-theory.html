ECG Signal Analysis

The PQRST Complex

The ECG represents the electrical activity of the heart, with each cardiac cycle producing a characteristic PQRST waveform:

  • P wave: Atrial depolarization (0.08-0.12s duration)
  • QRS complex: Ventricular depolarization (0.06-0.10s)
  • T wave: Ventricular repolarization
  • PR interval: AV conduction time (0.12-0.20s)
  • QT interval: Total ventricular activity

Pan-Tompkins R-Peak Detection

The Pan-Tompkins algorithm detects QRS complexes through a series of filters:

1. Bandpass filter (5-15 Hz): y[n] = x[n] - 2x[n-1] + x[n-2]
2. Derivative: y[n] = (1/8)(−x[n−2]−2x[n−1]+2x[n+1]+x[n+2])
3. Squaring: y[n] = x[n]²
4. Moving average: y[n] = (1/N)∑x[n-k], k=0 to N-1
5. Adaptive thresholding

Heart Rate Variability (HRV)

HRV metrics quantify beat-to-beat interval variations:

Time Domain:

SDNN = √(1/N ∑(RRᵢ - RR̄)²)
RMSSD = √(1/(N-1) ∑(RRᵢ₊₁ - RRᵢ)²)
pNN50 = (count of |RRᵢ₊₁ - RRᵢ| > 50ms) / N × 100%

Frequency Domain:

VLF: 0.003-0.04 Hz (thermoregulation)
LF:  0.04-0.15 Hz (sympathetic + parasympathetic)
HF:  0.15-0.4 Hz (parasympathetic/respiratory)
LF/HF ratio: Sympathovagal balance indicator

EEG Signal Analysis

Frequency Bands

EEG signals are characterized by distinct frequency bands associated with brain states:

Delta (δ): 0.5-4 Hz
Deep sleep, unconsciousness
Theta (θ): 4-8 Hz
Drowsiness, light sleep, meditation
Alpha (α): 8-13 Hz
Relaxed wakefulness, eyes closed
Beta (β): 13-30 Hz
Active thinking, focus, alertness
Gamma (γ): 30-100 Hz
Cognitive processing, perception, consciousness

Power Spectral Density

Welch's Method:
PSD(f) = (1/KMU) ∑|∑x[n]w[n]e^(-j2πfn)|²

Band Power:
P_band = ∫[f₁,f₂] PSD(f) df

Relative Power:
RP_band = P_band / P_total × 100%

Independent Component Analysis (ICA)

ICA separates EEG into independent source signals for artifact removal:

X = AS (mixing model)
S = WX (unmixing)

Maximize non-Gaussianity:
J(y) ∝ [E{G(y)} - E{G(ν)}]²

where G is a nonlinear function (e.g., G(u) = log cosh u)

Digital Filtering

IIR Filter Design

Infinite Impulse Response filters using bilinear transformation:

Butterworth (maximally flat):
|H(jω)|² = 1 / (1 + (ω/ωc)^(2N))

Bilinear Transform:
s = (2/T) × (z-1)/(z+1)

Transfer Function:
H(z) = (b₀ + b₁z⁻¹ + ... + bₘz⁻ᵐ) / (1 + a₁z⁻¹ + ... + aₙz⁻ⁿ)

FIR Filter Design

Window Method:
h[n] = hd[n] × w[n]

Ideal lowpass:
hd[n] = sin(ωc(n-M/2)) / (π(n-M/2))

Common windows:
Hamming: w[n] = 0.54 - 0.46cos(2πn/M)
Blackman: w[n] = 0.42 - 0.5cos(2πn/M) + 0.08cos(4πn/M)

EMG Analysis

Amplitude Features

RMS (Root Mean Square):
RMS = √(1/N ∑x[n]²)

MAV (Mean Absolute Value):
MAV = (1/N) ∑|x[n]|

Integrated EMG:
IEMG = ∑|x[n]|

Fatigue Analysis

Muscle fatigue causes a spectral shift to lower frequencies:

Median Frequency:
∫[0,MDF] PSD(f)df = ∫[MDF,∞] PSD(f)df

Mean Frequency:
MNF = ∫f×PSD(f)df / ∫PSD(f)df

Fatigue Index:
FI = (MDF_initial - MDF_final) / MDF_initial × 100%

Classification Methods

Support Vector Machine

Decision function:
f(x) = sign(∑αᵢyᵢK(xᵢ,x) + b)

RBF Kernel:
K(x,x') = exp(-γ||x-x'||²)

Convolutional Neural Network (1D)

Convolution:
y[n] = ∑w[k]×x[n-k] + b

Architecture:
Input → Conv1D → BatchNorm → ReLU → MaxPool →
Conv1D → BatchNorm → ReLU → GlobalAvgPool →
Dense → Softmax
