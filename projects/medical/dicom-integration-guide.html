What is DICOM?

DICOM (Digital Imaging and Communications in Medicine) is the international standard for medical images and related information. It defines formats for medical images and communication protocols for exchanging medical imaging information.

Reading DICOM Files

import pydicom
from pydicom.pixel_data_handlers import apply_voi_lut

# Read DICOM file
ds = pydicom.dcmread("scan.dcm")

# Get patient info
patient_name = ds.PatientName
study_date = ds.StudyDate

# Get pixel array with proper windowing
pixel_array = apply_voi_lut(ds.pixel_array, ds)
