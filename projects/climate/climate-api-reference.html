API Reference

Complete documentation for the Climate Forecasting API

Endpoints

POST /forecast GET /historical GET /weather GET /anomalies

Generate Forecast

POST /api/v1/forecast

Generate energy demand or weather forecast for specified horizon.

Request Body

{
  "target": "energy_demand",
  "region": "california",
  "horizon_hours": 168,
  "model": "hybrid",
  "include_weather": true,
  "confidence_level": 0.90,
  "granularity": "hourly"
}

Response

{
  "forecast_id": "fc_abc123",
  "target": "energy_demand",
  "region": "california",
  "created_at": "2024-01-15T10:00:00Z",
  "model_version": "v2.1.0",
  "predictions": [
    {
      "timestamp": "2024-01-15T11:00:00Z",
      "value": 38420,
      "lower_bound": 36500,
      "upper_bound": 40340,
      "components": {
        "trend": 35000,
        "daily": 2800,
        "weekly": 420,
        "holiday": 0,
        "residual": 200
      }
    }
  ],
  "metrics": {
    "expected_mape": 2.3,
    "model_confidence": 0.95
  }
}

Parameters

Parameter Type Description
targetstringenergy_demand, temperature, solar, wind
regionstringGeographic region code
horizon_hoursintForecast horizon (1-336 hours)
modelstringprophet, lstm, hybrid (default)
confidence_levelfloat0.80, 0.90, or 0.95

Get Historical Data

GET /api/v1/historical

Retrieve historical demand and weather data.

Query Parameters

GET /api/v1/historical?region=california&start=2024-01-01&end=2024-01-07&granularity=hourly

Response

{
  "region": "california",
  "start": "2024-01-01T00:00:00Z",
  "end": "2024-01-07T23:00:00Z",
  "granularity": "hourly",
  "data": [
    {
      "timestamp": "2024-01-01T00:00:00Z",
      "demand_mw": 32450,
      "temperature_f": 48.2,
      "humidity_pct": 72,
      "wind_mph": 8.5,
      "solar_mw": 0
    }
  ]
}
