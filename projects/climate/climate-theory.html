1. Time Series Fundamentals

Energy demand forecasting is a time series prediction problem. A time series can be decomposed into several components:

Additive Decomposition

Y(t) = T(t) + S(t) + C(t) + ε(t)
T(t) - Trend: Long-term direction
S(t) - Seasonality: Repeating patterns
C(t) - Cyclic: Non-fixed period fluctuations
ε(t) - Residual: Random noise

Key Seasonalities in Energy

  • Daily: Morning ramp, afternoon peak, evening decline
  • Weekly: Weekday vs weekend patterns
  • Yearly: Summer/winter demand cycles (HVAC driven)
  • Holiday effects: Significant demand drops on holidays

2. Facebook Prophet

Prophet is a decomposable model with trend, seasonality, and holidays:

y(t) = g(t) + s(t) + h(t) + εt

Trend Component g(t)

Prophet supports two trend models:

Linear Trend
g(t) = (k + a(t)·δ)t + (m + a(t)·γ)

Piecewise linear with changepoints

Logistic Growth
g(t) = C(t) / (1 + exp(-k(t - m)))

For saturating growth scenarios

Fourier Series for Seasonality

s(t) = Σ (ancos(2πnt/P) + bnsin(2πnt/P))

P = period (365.25 for yearly, 7 for weekly), n = number of Fourier terms

3. LSTM Networks

Long Short-Term Memory (LSTM) networks are specialized RNNs designed to learn long-range dependencies in sequential data.

LSTM Cell Equations

Forget Gate: ft = σ(Wf·[ht-1, xt] + bf)
Input Gate: it = σ(Wi·[ht-1, xt] + bi)
Cell State: Ct = ft⊙Ct-1 + it⊙tanh(WC·[ht-1, xt])
Output Gate: ot = σ(Wo·[ht-1, xt] + bo)

Why LSTM for Energy?

  • • Captures complex non-linear relationships
  • • Learns from raw multivariate inputs (demand, weather, calendar)
  • • Handles varying sequence lengths
  • • Can model regime changes and sudden shifts

4. Hybrid Prophet + LSTM

Combining Prophet's interpretable decomposition with LSTM's pattern learning yields superior forecasts:

Raw Data
Prophet (Trend + Seasonality)
Residuals
LSTM (Residual Patterns)
ŷ = Prophet(trend, seasonality, holidays) + LSTM(residuals, exogenous)

5. Forecast Evaluation Metrics

MAPE
100/n · Σ|y - ŷ|/|y|

Mean Absolute Percentage Error - scale-independent

RMSE
√(1/n · Σ(y - ŷ)²)

Root Mean Square Error - penalizes large errors

MAE
1/n · Σ|y - ŷ|

Mean Absolute Error - in original units

Skill Score
1 - RMSE/RMSEbaseline

Improvement over naive forecast
