Authentication

All API endpoints require authentication using API keys. Include your API key in the request header:

Authorization: Bearer YOUR_API_KEY

You can obtain an API key by contacting the system administrator or through the web interface.

Virtual Metrology API

POST Predict CD and Overlay
/api/v1/vm/predict
Predicts CD and overlay values for a given wafer using the trained virtual metrology model.

Request Body

{
  "wafer_id": "W001",
  "process_step": "litho",
  "features": {
    "feature_size": 50.0,
    "temperature": 100.0,
    "pressure": 10.0,
    "process_time": 60.0,
    "wafer_position": [0.5, 0.5]
  },
  "include_uncertainty": true
}

Response

{
  "success": true,
  "predictions": {
    "cd_prediction": 45.2,
    "overlay_prediction": 3.8,
    "confidence": 94.5,
    "uncertainty": 1.2
  },
  "feature_importance": {
    "feature_size": 0.35,
    "temperature": 0.25,
    "pressure": 0.15,
    "process_time": 0.12,
    "wafer_position": 0.08,
    "previous_cd": 0.05
  },
  "timestamp": "2024-01-15T10:30:00Z"
}
GET Get Model Performance
/api/v1/vm/performance
Retrieves the current performance metrics of the virtual metrology model.

Run-to-Run Control API

POST Calculate Control Action
/api/v1/r2r/control
Calculates the optimal control action for the next run based on current process state.

Request Body

{
  "target_cd": 50.0,
  "current_cd": 52.3,
  "control_mode": "double_ewma",
  "parameters": {
    "ewma_lambda": 0.3,
    "control_gain": 1.0,
    "feed_forward_weight": 0.7
  },
  "historical_data": [
    {"run": 1, "cd": 50.1, "control_action": 0.0},
    {"run": 2, "cd": 51.2, "control_action": -0.5}
  ]
}

Response

{
  "success": true,
  "control_action": -1.2,
  "predicted_cd": 49.8,
  "control_stability": 0.95,
  "constraints": {
    "min_action": -2.0,
    "max_action": 2.0,
    "action_applied": -1.2
  },
  "timestamp": "2024-01-15T10:30:00Z"
}

SPC/FDC API

POST Submit Process Data
/api/v1/spc/submit
Submits process data for statistical process control and fault detection.

Request Body

{
  "wafer_id": "W001",
  "process_step": "litho",
  "measurements": {
    "cd": 45.2,
    "overlay": 3.8,
    "temperature": 100.0,
    "pressure": 10.0
  },
  "timestamp": "2024-01-15T10:30:00Z"
}
GET Get SPC Charts
/api/v1/spc/charts
Retrieves SPC charts and control limits for monitoring.

Process Optimization API

POST Run Optimization
/api/v1/optimization/run
Runs multi-objective process optimization to find optimal parameters.

Request Body

{
  "optimization_mode": "pareto",
  "objectives": {
    "cd_weight": 0.4,
    "overlay_weight": 0.3,
    "sampling_weight": 0.3
  },
  "constraints": {
    "min_cd": 40.0,
    "max_cd": 60.0,
    "min_overlay": 0.0,
    "max_overlay": 10.0
  },
  "parameters": {
    "population_size": 50,
    "generations": 100,
    "mutation_rate": 0.1
  }
}

Error Codes

Code Message Description
400 Bad Request Invalid request parameters
401 Unauthorized Invalid or missing API key
404 Not Found Resource not found
500 Internal Server Error Server-side error

Integration Examples

Python Example

import requests
import json

# API Configuration
API_BASE_URL = "https://api.cross-fab.com/v1"
API_KEY = "your_api_key_here"

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

# Virtual Metrology Prediction
def predict_cd_overlay(wafer_id, features):
    url = f"{API_BASE_URL}/vm/predict"
    data = {
        "wafer_id": wafer_id,
        "process_step": "litho",
        "features": features,
        "include_uncertainty": True
    }
    
    response = requests.post(url, headers=headers, json=data)
    return response.json()

# Example usage
features = {
    "feature_size": 50.0,
    "temperature": 100.0,
    "pressure": 10.0,
    "process_time": 60.0,
    "wafer_position": [0.5, 0.5]
}

result = predict_cd_overlay("W001", features)
print(f"CD Prediction: {result['predictions']['cd_prediction']}")
print(f"Overlay Prediction: {result['predictions']['overlay_prediction']}")

JavaScript Example

// API Configuration
const API_BASE_URL = 'https://api.cross-fab.com/v1';
const API_KEY = 'your_api_key_here';

const headers = {
    'Authorization': `Bearer ${API_KEY}`,
    'Content-Type': 'application/json'
};

// Virtual Metrology Prediction
async function predictCDOverlay(waferId, features) {
    const url = `${API_BASE_URL}/vm/predict`;
    const data = {
        wafer_id: waferId,
        process_step: 'litho',
        features: features,
        include_uncertainty: true
    };
    
    try {
        const response = await fetch(url, {
            method: 'POST',
            headers: headers,
            body: JSON.stringify(data)
        });
        
        return await response.json();
    } catch (error) {
        console.error('Error:', error);
    }
}

// Example usage
const features = {
    feature_size: 50.0,
    temperature: 100.0,
    pressure: 10.0,
    process_time: 60.0,
    wafer_position: [0.5, 0.5]
};

predictCDOverlay('W001', features)
    .then(result => {
        console.log('CD Prediction:', result.predictions.cd_prediction);
        console.log('Overlay Prediction:', result.predictions.overlay_prediction);
    });
