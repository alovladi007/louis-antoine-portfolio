Ring Resonator Fundamentals

Silicon nitride (Si₃N₄) offers ultra-low propagation loss (0.1-1 dB/cm) enabling quality factors exceeding 10⁷. The ring resonator enhances light-matter interaction through cavity buildup, critical for efficient Kerr squeezing. Precise control of coupling gap and waveguide geometry determines Q-factor and escape efficiency.

Quality Factor Q:
Q_total = ω₀ / κ_total

κ_total = κ_ext + κ_int
κ_ext = external coupling rate (controllable)
κ_int = intrinsic loss rate (material + scattering + bending)
Critical Coupling Condition:
κ_ext = κ_int → Q_ext = Q_int

Power buildup at critical coupling: P_cavity = 4·Q²·P_in / (π²·V_eff)
Escape efficiency: η_esc = κ_ext / κ_total = 0.5 (at critical coupling)
Free Spectral Range (FSR):
FSR = c / (n_eff · L) = c / (n_eff · 2πR)

For R = 50 μm, n_eff = 1.95: FSR ≈ 308 GHz
Mode number m = ω₀ / (2π·FSR) ≈ 630 for λ = 1550 nm
Coupling Coefficient vs Gap:
κ_ext ∝ exp(-g/g₀)
g₀ ≈ λ / (2π·√(n_eff² - n_cladding²)) ≈ 100 nm for SiN

Typical coupling gap: 150-300 nm for critical coupling
Bending Loss (Whispering Gallery Mode):
α_bend = A · exp(-B·R/w)
A, B = material-dependent constants
w = waveguide width

For SiN strip: R > 20 μm → negligible bending loss
Thermal Resonance Tuning:
Δλ/ΔT = (dn/dT) · λ / n_eff

For SiN: dn/dT ≈ 2.5×10⁻⁵ K⁻¹
Tuning range: ~25 pm/K @ 1550 nm
