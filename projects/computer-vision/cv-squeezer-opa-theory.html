Optical Parametric Amplification

Second-order nonlinear optics in TFLN for squeezed light generation via SPDC

χ⁽²⁾ Nonlinear Interaction

Optical parametric amplification exploits the second-order nonlinearity (χ⁽²⁾) in non-centrosymmetric crystals like lithium niobate. A strong pump photon (ω_p) spontaneously decays into signal (ω_s) and idler (ω_i) photons via spontaneous parametric down-conversion (SPDC). In the degenerate case (ω_s = ω_i = ω_p/2), this produces amplitude squeezing.

Three-Wave Mixing Hamiltonian:
Ĥ_OPA = iħ · χ⁽²⁾ · (â†_s · â†_i · â_p - â_s · â_i · â†_p)

For degenerate OPA: ω_s = ω_i = ω_probe
Energy conservation: ω_p = ω_s + ω_i
Momentum conservation: k_p = k_s + k_i (phase matching)
Coupled-Mode Equations (Slowly Varying Envelope):
dA_s/dz = -iκ · A*_i · A_p · exp(iΔk·z)
dA_i/dz = -iκ · A*_s · A_p · exp(iΔk·z)
dA_p/dz = -iκ · A_s · A_i · exp(-iΔk·z)

where κ = (ω · d_eff) / (n·c), Δk = k_p - k_s - k_i (phase mismatch)
Squeezing Parameter (Undepleted Pump):
r = κ · |A_p| · L = (χ⁽²⁾ · E_p · L) / (2·√(ε₀·c·ħω))

Quadrature variances: V_x = e^(-2r), V_p = e^(+2r)
Detected squeezing: S_dB = 10 · log₁₀(V_x) = -20·r·log₁₀(e) ≈ -8.686·r dB
Quasi-Phase-Matching (QPM):
Effective nonlinearity: d_eff = (2/π) · d₃₃ · |sin(πm/2)|
Poling period: Λ = λ_p / (2·(n_p - n_s)) for first-order (m=1)

QPM compensates for: Δk = 2π/Λ - (k_p - k_s - k_i) = 0
Phase-Matching Types:
Type-0: e_p → e_s + e_i (all extraordinary polarization)
Type-I: e_p → o_s + o_i (signal/idler ordinary, pump extraordinary)
Type-II: e_p → e_s + o_i (orthogonal signal/idler polarizations)
