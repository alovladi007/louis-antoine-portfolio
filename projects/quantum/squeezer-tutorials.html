Tutorial 8 60 min

Squeezed Light for CV-QKD

Integrate squeezed states into continuous-variable quantum key distribution systems for enhanced secret key rates. 

from cv_squeezer import SqueezerSimulator
from cvqkd import KeyRateCalculator

# Generate squeezed state
squeezer = SqueezerSimulator("tfln", 1550e-9)
sigma = squeezer.get_covariance_matrix(r=1.0)

# Calculate QKD improvement
qkd = KeyRateCalculator(distance=25)
rate_coherent = qkd.key_rate(V_mod=4)
rate_squeezed = qkd.key_rate_squeezed(sigma)

Quick Reference

Common Conversions

3 dB → r ≈ 0.35

6 dB → r ≈ 0.69

10 dB → r ≈ 1.15

15 dB → r ≈ 1.73

Key Formulas

V_sq = e^(-2r)

V_anti = e^(+2r)

V_det = η×V + (1-η)

dB = 10×log₁₀(V)

Typical Values

SiN: 3-10 dB squeezing

TFLN: 10-15+ dB squeezing

η_escape: 80-95%

η_det: 90-98%
