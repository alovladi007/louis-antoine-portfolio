Tutorial 1: Getting Started with Preston Simulator

Beginner

Learning Objectives

  • Understand the Preston equation and its parameters
  • Calculate material removal rate for basic CMP scenarios
  • Interpret simulation results
  • Adjust process parameters to meet target specifications

Prerequisites

  • Basic understanding of semiconductor fabrication
  • Familiarity with JavaScript syntax
  • Access to the CMP Simulator codebase
1

Import the CMP Simulator Library

First, include the CMP simulator library in your HTML file or JavaScript project. This library contains all the core functions for Preston equation calculations.

// Import the CMP simulator module import { calculateMRR, calculateVelocityProfile } from './cmp-simulator.js'; // Or using script tag in HTML: // <script src="cmp-simulator.js"></script>
Tip: Make sure the cmp-simulator.js file is in the same directory or adjust the path accordingly.
2

Define Process Parameters

Set up the basic process parameters for your CMP simulation. These include pressure, velocity, and the Preston coefficient specific to your material-slurry combination.

// Define process parameters for copper CMP const processParams = { pressure: 21000, // Applied pressure in Pascal (3 psi) velocity: 1.5, // Relative velocity in m/s prestonCoeff: 1.2e-13, // Preston coefficient in Pa^-1 temperature: 298 // Temperature in Kelvin (25°C) }; console.log('Process Parameters:', processParams);
Note: The Preston coefficient varies significantly between materials and slurries. Use experimental data or literature values for accurate simulations.
3

Calculate Material Removal Rate

Use the calculateMRR() function to compute the material removal rate based on your process parameters.

// Calculate the material removal rate const mrr = calculateMRR( processParams.pressure, processParams.velocity, processParams.prestonCoeff, { temperature: processParams.temperature, units: 'nm/min' } ); console.log(`Material Removal Rate: ${mrr.toFixed(1)} nm/min`);

Expected Output:

Material Removal Rate: 227.0 nm/min
4

Validate Against Target Specifications

Compare your calculated removal rate against the target specification and determine if adjustments are needed.

// Define target specification const targetMRR = 250; // Target: 250 nm/min const tolerance = 0.1; // ±10% // Check if within specification const lowerBound = targetMRR * (1 - tolerance); const upperBound = targetMRR * (1 + tolerance); if (mrr >= lowerBound && mrr <= upperBound) { console.log('✓ MRR is within specification'); } else { console.log('✗ MRR adjustment needed'); const adjustment = ((targetMRR - mrr) / mrr * 100).toFixed(1); console.log(` Increase MRR by ${adjustment}%`); }

Expected Output:

✗ MRR adjustment needed
  Increase MRR by 10.1%
5

Adjust Parameters to Meet Target

Modify pressure or velocity to achieve the target removal rate. The Preston equation shows that MRR is proportional to pressure × velocity.

// Calculate required adjustment factor const adjustmentFactor = targetMRR / mrr; // Option 1: Increase pressure const newPressure = processParams.pressure * adjustmentFactor; console.log(`Option 1 - New pressure: ${(newPressure / 1000).toFixed(1)} kPa`); // Option 2: Increase velocity const newVelocity = processParams.velocity * adjustmentFactor; console.log(`Option 2 - New velocity: ${newVelocity.toFixed(2)} m/s`); // Option 3: Balanced adjustment (increase both moderately) const balancedFactor = Math.sqrt(adjustmentFactor); const balancedPressure = processParams.pressure * balancedFactor; const balancedVelocity = processParams.velocity * balancedFactor; console.log(`Option 3 - Balanced:`); console.log(` Pressure: ${(balancedPressure / 1000).toFixed(1)} kPa`); console.log(` Velocity: ${balancedVelocity.toFixed(2)} m/s`); // Verify the balanced adjustment const verifyMRR = calculateMRR( balancedPressure, balancedVelocity, processParams.prestonCoeff ); console.log(`\nVerified MRR: ${verifyMRR.toFixed(1)} nm/min`);

Expected Output:

Option 1 - New pressure: 23.1 kPa
Option 2 - New velocity: 1.65 m/s
Option 3 - Balanced:
  Pressure: 21.9 kPa
  Velocity: 1.57 m/s

Verified MRR: 250.0 nm/min
Best Practice: A balanced adjustment is often preferred as it minimizes stress on individual parameters and provides better process stability.

Tutorial 2: Optimizing Copper CMP Recipe

Intermediate

Learning Objectives

  • Set up multi-objective optimization problems
  • Balance removal rate, uniformity, and defect constraints
  • Use gradient-based and evolutionary optimization algorithms
  • Analyze and validate optimization results

Prerequisites

  • Completion of Tutorial 1
  • Understanding of CMP process variables
  • Familiarity with optimization concepts
1

Define Optimization Objectives

Specify your target removal rate, maximum allowable non-uniformity, and defect density constraints.

import { optimizeRecipe, calculateUniformity } from './cmp-simulator.js'; // Define optimization objectives const objectives = { targetMRR: 250, // Target removal rate: 250 nm/min maxNonUniformity: 3, // Max WIWNU: 3% maxDefects: 10, // Max defects/wafer targetSelectivity: 50 // Cu:TaN selectivity > 50:1 }; console.log('Optimization Objectives:', objectives);
2

Set Parameter Constraints

Define acceptable ranges for process parameters based on tool capabilities and safety limits.

// Define parameter constraints const constraints = { pressureRange: [14000, 35000], // 2-5 psi in Pascal velocityRange: [0.8, 2.5], // 0.8-2.5 m/s flowRange: [100, 400], // 100-400 mL/min temperatureRange: [293, 308], // 20-35°C in Kelvin h2o2Range: [0.01, 0.08] // 1-8% H2O2 concentration }; console.log('Parameter Constraints:', constraints);
Note: Always verify constraints against your specific tool specifications and safety guidelines before running experiments.
3

Provide Initial Guess

Start with a reasonable initial recipe based on process knowledge or literature values.

// Initial recipe guess (baseline recipe) const initialGuess = { pressure: 21000, // 3 psi velocity: 1.5, // m/s flow: 200, // mL/min temperature: 298, // 25°C h2o2Concentration: 0.05, // 5% pH: 4.5 }; console.log('Initial Recipe:', initialGuess);
4

Run Optimization Algorithm

Execute the optimization using a genetic algorithm for robust global optimization.

// Run optimization const optimizationResult = optimizeRecipe( objectives, constraints, initialGuess, 'genetic' // Algorithm: 'genetic', 'nelder-mead', or 'gradient-descent' ); console.log('\n=== Optimization Complete ==='); console.log('Iterations:', optimizationResult.iterations); console.log('Convergence:', optimizationResult.convergence); console.log('\nOptimal Parameters:', optimizationResult.optimalParams); console.log('\nAchieved Objectives:', optimizationResult.achievedObjectives);

Expected Output:

=== Optimization Complete ===
Iterations: 156
Convergence: true

Optimal Parameters: {
  pressure: 23150,
  velocity: 1.62,
  flow: 225,
  temperature: 301,
  h2o2Concentration: 0.055,
  pH: 4.3
}

Achieved Objectives: {
  mrr: 249.8,
  nonUniformity: 2.7,
  defects: 8,
  selectivity: 52.3
}
Tip: Genetic algorithms are slower but more robust for multi-modal optimization landscapes. Use gradient-descent for fine-tuning around a known optimum.
5

Analyze Sensitivity

Perform sensitivity analysis to understand which parameters most strongly affect your objectives.

// Perform sensitivity analysis const params = optimizationResult.optimalParams; const perturbation = 0.05; // 5% perturbation function analyzeSensitivity(baseParams, paramName) { const baseValue = baseParams[paramName]; const increased = { ...baseParams, [paramName]: baseValue * (1 + perturbation) }; const decreased = { ...baseParams, [paramName]: baseValue * (1 - perturbation) }; const baseMRR = simulateMRR(baseParams); const increasedMRR = simulateMRR(increased); const decreasedMRR = simulateMRR(decreased); const sensitivity = (increasedMRR - decreasedMRR) / (2 * perturbation * baseMRR); return { parameter: paramName, sensitivity: sensitivity, impact: Math.abs(sensitivity) }; } // Analyze each parameter const sensitivities = ['pressure', 'velocity', 'h2o2Concentration', 'temperature'] .map(param => analyzeSensitivity(params, param)) .sort((a, b) => b.impact - a.impact); console.log('\nSensitivity Analysis (ranked by impact):'); sensitivities.forEach(s => { console.log(` ${s.parameter}: ${s.sensitivity.toFixed(3)}`); });

Expected Output:

Sensitivity Analysis (ranked by impact):
  pressure: 0.987
  velocity: 0.982
  h2o2Concentration: 0.456
  temperature: 0.234
6

Validate with Uniformity Prediction

Simulate the wafer-level uniformity with the optimized recipe to ensure it meets specifications.

// Simulate uniformity across wafer const waferDiameter = 300; // 300mm wafer const radialPoints = [0, 25, 50, 75, 100, 125, 145]; // mm from center const velocityProfile = calculateVelocityProfile( radialPoints, 93, // platen RPM 87 // carrier RPM ); const mrrProfile = radialPoints.map((r, i) => ({ radius: r, velocity: velocityProfile[i], mrr: calculateMRR(params.pressure, velocityProfile[i], 1.2e-13) })); const uniformity = calculateUniformity( mrrProfile.map(p => p.mrr), 'wiwnu' ); console.log('\nWafer Uniformity Analysis:'); console.log(` WIWNU: ${uniformity.uniformity.toFixed(2)}%`); console.log(` Mean MRR: ${uniformity.mean.toFixed(1)} nm/min`); console.log(` Std Dev: ${uniformity.stdDev.toFixed(1)} nm/min`); console.log(` Min: ${uniformity.min.toFixed(1)} nm/min (r=${mrrProfile[uniformity.minIndex].radius}mm)`); console.log(` Max: ${uniformity.max.toFixed(1)} nm/min (r=${mrrProfile[uniformity.maxIndex].radius}mm)`);
7

Calculate Cost Impact

Evaluate the economic implications of the optimized recipe.

// Calculate cost of ownership const cost = calculateCostOfOwnership( { polishTime: 60, // seconds slurryFlow: params.flow // mL/min }, { slurryCost: 0.15, // $/mL padCost: 1200, // $/pad padLife: 500 // wafers/pad }, { depreciationRate: 0.05, // $/wafer powerCost: 0.02 // $/wafer }, 60 // throughput: wafers/hour ); console.log('\nCost Analysis:'); console.log(` Total Cost: $${cost.costPerWafer.toFixed(3)}/wafer`); console.log(` Breakdown:`); console.log(` Slurry: $${cost.breakdown.slurry.toFixed(3)}`); console.log(` Pad: $${cost.breakdown.pad.toFixed(3)}`); console.log(` Tool: $${cost.breakdown.tool.toFixed(3)}`); console.log(` Power: $${cost.breakdown.power.toFixed(3)}`);
8

Generate Optimization Report

Create a comprehensive report summarizing the optimization results.

// Generate report const report = generateReport( { initial: initialGuess, optimized: params, objectives: optimizationResult.achievedObjectives, uniformity: uniformity, cost: cost, sensitivity: sensitivities }, 'detailed', { includeCharts: true, format: 'html' } ); // Save or display report console.log('\nOptimization report generated successfully!'); console.log('View report at: optimization_report.html');

Tutorial 3: Analyzing Uniformity Data

Beginner

Learning Objectives

  • Import and process measurement data from metrology tools
  • Calculate various uniformity metrics (WIWNU, range, 3-sigma)
  • Create wafer maps and radial profile visualizations
  • Identify and filter outliers in measurement data

This tutorial guides you through processing experimental thickness measurements, calculating uniformity statistics, generating visual wafer maps, and interpreting results to identify process issues.

// Load measurement data from CSV or metrology tool export const rawData = loadMeasurementData('thickness_data.csv'); // Filter outliers using IQR method const filtered = filterOutliers(rawData, 'iqr', 1.5); // Calculate uniformity metrics const uniformity = calculateUniformity(filtered.filteredData, 'wiwnu'); // Generate wafer map visualization const waferMap = interpolateWaferMap( rawData.map(d => ({ x: d.x, y: d.y, value: d.thickness })), 100, 'cubic' ); plotWaferMap(waferMap, canvas, 'viridis', { showScale: true, title: 'Post-CMP Thickness Uniformity' });

Key Takeaways

  • WIWNU less than 3% indicates good process control
  • Edge exclusion zones are critical for accurate uniformity calculation
  • Radial symmetry in wafer maps indicates well-balanced pressure/velocity

Tutorial 4: Running ML Predictions

Advanced

Learning Objectives

  • Prepare training data from historical CMP runs
  • Train neural network models for MRR and uniformity prediction
  • Validate model performance using cross-validation
  • Deploy models for real-time process prediction

Machine learning models can capture complex non-linear relationships in CMP processes that analytical models may miss. This tutorial shows how to train predictive models using historical data.

// Prepare training dataset const trainingData = prepareMLDataset({ features: ['pressure', 'velocity', 'flow', 'temperature', 'h2o2', 'pH'], targets: ['mrr', 'uniformity', 'defects'], normalize: true }); // Define neural network architecture const model = createNeuralNetwork({ inputDim: 6, hiddenLayers: [32, 16, 8], outputDim: 3, activation: 'relu', optimizer: 'adam' }); // Train model with cross-validation const results = await trainModel(model, trainingData, { epochs: 200, batchSize: 32, validationSplit: 0.2, earlyStopping: true }); console.log(`Training complete - R²: ${results.r_squared.toFixed(3)}`);
Important: ML models require substantial training data (100+ experiments) to generalize well. Always validate predictions against physics-based models and actual experiments.

Tutorial 8: Multi-Step Process Optimization

Advanced

Learning Objectives

  • Design multi-step CMP sequences for damascene structures
  • Optimize step timing and transitions
  • Minimize dishing and erosion across all steps
  • Integrate endpoint detection for each step

Advanced damascene CMP requires multiple polish steps with different selectivities. This tutorial shows how to optimize the entire sequence.

// Define 3-step Cu damascene process const multiStepProcess = [ { name: 'Step 1: Bulk Cu Removal', target: 'high-rate', slurry: 'Cu-bulk', duration: 45, endpointMethod: 'motor-current' }, { name: 'Step 2: Barrier Clearing', target: 'high-selectivity', slurry: 'Cu-barrier', duration: 30, endpointMethod: 'optical' }, { name: 'Step 3: Buff', target: 'low-defect', slurry: 'buff-slurry', duration: 20, endpointMethod: 'timed' } ]; // Optimize entire sequence const optimized = optimizeMultiStepProcess(multiStepProcess, objectives);
Best Practice: Always include a soft buff step at the end to minimize defects and improve surface finish before post-CMP cleaning.
