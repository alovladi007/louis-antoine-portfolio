Preston Calculations

calculateMRR()

calculateMRR(pressure, velocity, prestonCoefficient, options)

Calculates the material removal rate using the Preston equation. This is the fundamental function for predicting removal rates in CMP processes.

Parameters

Name Type Description Default
pressure number Applied pressure in Pascal (Pa) -
velocity number Relative velocity in m/s -
prestonCoefficient number Preston coefficient (K_p) in Pa^-1 -
options Object Optional configuration object {}
options.temperature number Temperature in Kelvin 298
options.units string 'nm/min' or 'angstrom/min' 'nm/min'

Returns

number - Material removal rate in specified units

Example Usage

// Calculate MRR for copper CMP const pressure = 21000; // 3 psi in Pa const velocity = 1.5; // m/s const kp = 1.2e-13; // Pa^-1 const mrr = calculateMRR(pressure, velocity, kp, { temperature: 303, units: 'nm/min' }); console.log(`Removal rate: ${mrr} nm/min`); // Output: Removal rate: 227 nm/min
Note: The Preston coefficient is material and slurry-dependent. Use experimental data to determine the appropriate value for your process.

calculatePrestonCoefficient()

calculatePrestonCoefficient(experimentalData, method)

Determines the Preston coefficient from experimental removal rate data using linear regression or non-linear fitting methods.

Parameters

Name Type Description
experimentalData Array<Object> Array of experimental data points with {pressure, velocity, mrr} properties
method string 'linear' or 'weighted-least-squares'

Returns

Object - {coefficient: number, r_squared: number, confidence_interval: Array}

Example Usage

const data = [ { pressure: 14000, velocity: 1.0, mrr: 145 }, { pressure: 21000, velocity: 1.0, mrr: 218 }, { pressure: 28000, velocity: 1.0, mrr: 291 } ]; const result = calculatePrestonCoefficient(data, 'linear'); console.log(`K_p = ${result.coefficient.toExponential(2)}`); console.log(`R² = ${result.r_squared}`);

calculateVelocityProfile()

calculateVelocityProfile(radius, plattenSpeed, carrierSpeed)

Calculates the relative velocity at different radial positions on the wafer for a rotational CMP tool.

Parameters

Name Type Description
radius number | Array Radial position(s) from wafer center (mm)
plattenSpeed number Platen rotation speed (RPM)
carrierSpeed number Carrier rotation speed (RPM)

Returns

number | Array<number> - Velocity in m/s at specified radius/radii

Example Usage

// Calculate velocity profile across wafer const radii = [0, 25, 50, 75, 100, 150]; // mm const velocities = calculateVelocityProfile(radii, 93, 87); velocities.forEach((v, i) => { console.log(`r=${radii[i]}mm: v=${v.toFixed(2)} m/s`); });

calculateTemperatureCorrectedMRR()

calculateTemperatureCorrectedMRR(mrrBase, tempActual, tempRef, activationEnergy)

Applies Arrhenius temperature correction to the material removal rate.

Parameters

Name Type Description
mrrBase number Base removal rate at reference temperature
tempActual number Actual process temperature (K)
tempRef number Reference temperature (K)
activationEnergy number Activation energy (kJ/mol)

Returns

number - Temperature-corrected removal rate

Example Usage

const mrrCorrected = calculateTemperatureCorrectedMRR( 200, // Base MRR: 200 nm/min at 25°C 308, // Actual temp: 35°C = 308K 298, // Reference temp: 25°C = 298K 45 // Activation energy: 45 kJ/mol ); console.log(`Corrected MRR: ${mrrCorrected.toFixed(1)} nm/min`);

Contact Mechanics

calculateRealContactArea()

calculateRealContactArea(nominalArea, pressure, padProperties)

Calculates the real contact area between pad and wafer using the Greenwood-Williamson model.

Parameters

Name Type Description
nominalArea number Nominal contact area (m²)
pressure number Applied pressure (Pa)
padProperties Object {roughness, asperityDensity, asperityRadius, elasticModulus, poissonRatio}

Returns

Object - {realArea: number, contactFraction: number, avgPressure: number}

Example Usage

const padProps = { roughness: 5e-6, // 5 μm RMS asperityDensity: 1e10, // per m² asperityRadius: 20e-6, // 20 μm elasticModulus: 500e6, // 500 MPa poissonRatio: 0.4 }; const contact = calculateRealContactArea(0.01, 21000, padProps); console.log(`Real area: ${(contact.realArea * 1e4).toFixed(2)} cm²`); console.log(`Contact fraction: ${(contact.contactFraction * 100).toFixed(2)}%`);

Optimization Functions

optimizeRecipe()

optimizeRecipe(objectives, constraints, initialGuess, algorithm)

Multi-objective optimization of CMP recipe parameters to achieve target removal rate, uniformity, and defect levels.

Parameters

Name Type Description
objectives Object {targetMRR, maxNonUniformity, maxDefects}
constraints Object {pressureRange, velocityRange, flowRange}
initialGuess Object {pressure, velocity, flow, temperature}
algorithm string 'nelder-mead', 'genetic', or 'gradient-descent'

Returns

Object - {optimalParams, achievedObjectives, convergence}

Example Usage

const result = optimizeRecipe({ targetMRR: 250, maxNonUniformity: 3, maxDefects: 10 }, { pressureRange: [14000, 35000], velocityRange: [0.8, 2.0], flowRange: [100, 300] }, { pressure: 21000, velocity: 1.5, flow: 200, temperature: 298 }, 'genetic'); console.log('Optimal recipe:', result.optimalParams);
