Basic Material Removal Rate Calculation

▼

This example demonstrates the fundamental Preston equation calculation for determining material removal rate (MRR). The Preston equation is the cornerstone of CMP modeling, relating removal rate to applied pressure and relative velocity.

Preston Equation Beginner Core Function
JavaScript 
/**
 * Basic Material Removal Rate Calculation
 * Demonstrates the Preston equation: MRR = Kp × P × V
 */

import { calculateMRR } from './cmp-simulator.js';

// Define process parameters
const pressure = 21000;          // Applied pressure in Pascal (3 psi)
const velocity = 1.5;             // Relative velocity in m/s
const prestonCoefficient = 1.2e-13; // Preston coefficient for Cu in Pa^-1

// Calculate material removal rate
const mrr = calculateMRR(
    pressure,
    velocity,
    prestonCoefficient,
    {
        temperature: 298,      // 25°C in Kelvin
        units: 'nm/min'        // Output units
    }
);

// Display results
console.log('=== Preston Equation Results ===');
console.log(`Pressure: ${(pressure / 1000).toFixed(1)} kPa (3 psi)`);
console.log(`Velocity: ${velocity} m/s`);
console.log(`Preston Coefficient: ${prestonCoefficient.toExponential(2)} Pa^-1`);
console.log(`\nMaterial Removal Rate: ${mrr.toFixed(1)} nm/min`);

// Convert to other common units
const mrrAngstromMin = mrr * 10;
const mrrNmSec = mrr / 60;
const mrrUmMin = mrr / 1000;

console.log('\n=== Unit Conversions ===');
console.log(`${mrrAngstromMin.toFixed(1)} Å/min`);
console.log(`${mrrNmSec.toFixed(2)} nm/s`);
console.log(`${mrrUmMin.toFixed(3)} μm/min`);

// Calculate material removed in a typical 60-second polish
const polishTime = 60; // seconds
const totalRemoval = mrrNmSec * polishTime;

console.log(`\nMaterial removed in ${polishTime}s: ${totalRemoval.toFixed(1)} nm`);

Key Concepts Explained

Preston Equation The fundamental relationship MRR = K_p × P × V shows that removal rate is proportional to the product of pressure and velocity.
Preston Coefficient (K_p) Material and slurry-specific constant that encapsulates chemical and mechanical properties. Must be determined experimentally.
Pressure Units CMP pressures typically range from 2-5 psi (14-35 kPa). Always use consistent SI units (Pascal) in calculations.
Typical Removal Rates Copper: 200-400 nm/min, Tungsten: 150-300 nm/min, Oxide: 100-200 nm/min with appropriate slurries.

Expected Output

=== Preston Equation Results === Pressure: 21.0 kPa (3 psi) Velocity: 1.5 m/s Preston Coefficient: 1.20e-13 Pa^-1 Material Removal Rate: 227.0 nm/min === Unit Conversions === 2270.0 Å/min 3.78 nm/s 0.227 μm/min Material removed in 60s: 227.0 nm

Customization Options

  • Adjust prestonCoefficient for different materials (W: 8e-14, SiO2: 5e-14)
  • Include temperature effects by varying the temperature parameter
  • Calculate for different tool configurations by modifying pressure and velocity
  • Add error handling for invalid parameter ranges

Velocity Profile Across Wafer

▼

Calculate the relative velocity distribution across a wafer for rotational CMP tools. This is essential for understanding and predicting removal uniformity patterns.

Kinematics Beginner Uniformity
JavaScript 
/**
 * Velocity Profile Calculation
 * Calculates relative velocity at different radial positions on the wafer
 */

import { calculateVelocityProfile } from './cmp-simulator.js';

// Tool configuration
const plattenRPM = 93;        // Platen rotation speed
const carrierRPM = 87;        // Carrier rotation speed
const waferDiameter = 300;    // 300mm wafer

// Define measurement points (radial positions in mm)
const radialPositions = [
    0,      // Center
    25,     // Inner zone
    50,     // Mid inner
    75,     // Middle
    100,    // Mid outer
    125,    // Outer zone
    145     // Edge (5mm exclusion)
];

// Calculate velocity profile
const velocities = calculateVelocityProfile(
    radialPositions,
    plattenRPM,
    carrierRPM
);

// Display results in table format
console.log('=== Velocity Profile Across Wafer ===');
console.log(`Platen Speed: ${plattenRPM} RPM`);
console.log(`Carrier Speed: ${carrierRPM} RPM`);
console.log('\nRadius (mm) | Velocity (m/s) | Relative to Center');
console.log('------------|---------------|-------------------');

radialPositions.forEach((r, i) => {
    const v = velocities[i];
    const relative = velocities[0] > 0 ? (v / velocities[0] * 100) : 0;
    console.log(`${r.toString().padStart(11)} | ${v.toFixed(3).padStart(13)} | ${relative.toFixed(1)}%`);
});

// Calculate velocity-based non-uniformity
const vMin = Math.min(...velocities);
const vMax = Math.max(...velocities);
const vMean = velocities.reduce((a, b) => a + b) / velocities.length;
const velocityNU = ((vMax - vMin) / vMean * 100);

console.log(`\n=== Velocity Statistics ===');
console.log(`Min Velocity: ${vMin.toFixed(3)} m/s at r=${radialPositions[velocities.indexOf(vMin)]}mm`);
console.log(`Max Velocity: ${vMax.toFixed(3)} m/s at r=${radialPositions[velocities.indexOf(vMax)]}mm`);
console.log(`Mean Velocity: ${vMean.toFixed(3)} m/s`);
console.log(`Velocity Non-Uniformity: ${velocityNU.toFixed(2)}%`);

// Predict MRR profile (assuming constant pressure)
const pressure = 21000;
const kp = 1.2e-13;

console.log('\n=== Predicted MRR Profile ===');
const mrrProfile = velocities.map((v, i) => {
    const mrr = kp * pressure * v * 60 * 1e9; // Convert to nm/min
    console.log(`r=${radialPositions[i]}mm: ${mrr.toFixed(1)} nm/min`);
    return mrr;
});

// Calculate predicted removal non-uniformity
const mrrMin = Math.min(...mrrProfile);
const mrrMax = Math.max(...mrrProfile);
const mrrMean = mrrProfile.reduce((a, b) => a + b) / mrrProfile.length;
const mrrNU = ((mrrMax - mrrMin) / mrrMean * 100);

console.log(`\nPredicted MRR Non-Uniformity: ${mrrNU.toFixed(2)}%`);

Key Concepts Explained

Relative Velocity In rotational CMP, velocity varies with radial position. Center velocity can be near zero if platen and carrier speeds are balanced.
Speed Matching Carrier and platen speeds are typically close (e.g., 87 vs 93 RPM) to minimize center-edge velocity variation.
Edge Exclusion The outer 5mm of the wafer is typically excluded from uniformity calculations due to edge effects.
Velocity Impact on MRR Velocity non-uniformity directly translates to MRR non-uniformity at constant pressure.

Expected Output

=== Velocity Profile Across Wafer === Platen Speed: 93 RPM Carrier Speed: 87 RPM Radius (mm) | Velocity (m/s) | Relative to Center ------------|---------------|------------------- 0 | 0.157 | 100.0% 25 | 0.786 | 500.6% 50 | 1.257 | 800.6% 75 | 1.571 | 1000.6% 100 | 1.728 | 1100.6% 125 | 1.728 | 1100.6% 145 | 1.571 | 1000.6% === Velocity Statistics === Min Velocity: 0.157 m/s at r=0mm Max Velocity: 1.728 m/s at r=100mm Mean Velocity: 1.257 m/s Velocity Non-Uniformity: 124.90% === Predicted MRR Profile === r=0mm: 23.7 nm/min r=25mm: 118.6 nm/min r=50mm: 189.7 nm/min r=75mm: 237.1 nm/min r=100mm: 260.7 nm/min r=125mm: 260.7 nm/min r=145mm: 237.1 nm/min Predicted MRR Non-Uniformity: 124.90%

Customization Options

  • Modify RPM values to optimize uniformity (try plattenRPM = carrierRPM for minimum center velocity)
  • Add pressure profiling to compensate for velocity non-uniformity
  • Include eccentricity effects by adding offset between wafer and platen centers
  • Calculate time-averaged velocity for oscillating carriers

Temperature-Dependent MRR Calculation

▼

Account for temperature effects on removal rate using the Arrhenius relationship. Temperature variations significantly impact chemical reaction rates in CMP processes.

Thermochemistry Intermediate Preston Model
JavaScript 
/**
 * Temperature-Dependent Material Removal Rate
 * Demonstrates Arrhenius correction for temperature effects
 */

import {
    calculateMRR,
    calculateTemperatureCorrectedMRR,
    calculateFrictionalHeat,
    calculateInterfaceTemperature
} from './cmp-simulator.js';

// Base process conditions (reference temperature)
const baseConditions = {
    pressure: 21000,                // Pa
    velocity: 1.5,                  // m/s
    prestonCoeff: 1.2e-13,          // Pa^-1
    referenceTemp: 298,             // 25°C in Kelvin
    activationEnergy: 45            // kJ/mol (typical for Cu CMP)
};

// Calculate base MRR at reference temperature
const baseMRR = calculateMRR(
    baseConditions.pressure,
    baseConditions.velocity,
    baseConditions.prestonCoeff
);

console.log('=== Temperature Effects on MRR ===');
console.log(`Reference Temperature: ${baseConditions.referenceTemp}K (${(baseConditions.referenceTemp - 273)}°C)`);
console.log(`Base MRR: ${baseMRR.toFixed(1)} nm/min`);
console.log(`Activation Energy: ${baseConditions.activationEnergy} kJ/mol\n`);

// Calculate MRR at different temperatures
const temperatures = [293, 298, 303, 308, 313]; // 20°C to 40°C

console.log('Temperature (°C) | Temperature (K) | MRR (nm/min) | Change from Ref');
console.log('-----------------|-----------------|--------------|----------------');

const temperatureData = temperatures.map(temp => {
    const correctedMRR = calculateTemperatureCorrectedMRR(
        baseMRR,
        temp,
        baseConditions.referenceTemp,
        baseConditions.activationEnergy
    );

    const change = ((correctedMRR - baseMRR) / baseMRR * 100);
    const celsius = temp - 273;

    console.log(
        `${celsius.toString().padStart(16)} | ` +
        `${temp.toString().padStart(15)} | ` +
        `${correctedMRR.toFixed(1).padStart(12)} | ` +
        `${change > 0 ? '+' : ''}${change.toFixed(1)}%`
    );

    return { temp, correctedMRR, change };
});

// Calculate interface temperature rise from friction
console.log('\n=== Frictional Heating Analysis ===');

const coefficientOfFriction = 0.3;
const waferArea = Math.PI * Math.pow(0.15, 2); // 300mm wafer in m²

const heatGeneration = calculateFrictionalHeat(
    coefficientOfFriction,
    baseConditions.pressure,
    waferArea,
    baseConditions.velocity
);

console.log(`Coefficient of Friction: ${coefficientOfFriction}`);
console.log(`Heat Generation: ${heatGeneration.toFixed(1)} W`);

// Calculate interface temperature with cooling
const slurryFlowRate = 200; // mL/min
const ambientTemp = 298;   // K

const interfaceTemp = calculateInterfaceTemperature(
    heatGeneration,
    slurryFlowRate * 1e-6 / 60, // Convert to m³/s
    ambientTemp,
    {
        conductivity: 0.6,       // W/m·K (water-based slurry)
        heatCapacity: 4180,      // J/kg·K
        density: 1000            // kg/m³
    }
);

console.log(`Slurry Flow Rate: ${slurryFlowRate} mL/min`);
console.log(`Ambient Temperature: ${(ambientTemp - 273)}°C`);
console.log(`Interface Temperature: ${(interfaceTemp - 273).toFixed(1)}°C`);
console.log(`Temperature Rise: ${(interfaceTemp - ambientTemp).toFixed(1)}°C`);

// Calculate actual MRR accounting for temperature rise
const actualMRR = calculateTemperatureCorrectedMRR(
    baseMRR,
    interfaceTemp,
    baseConditions.referenceTemp,
    baseConditions.activationEnergy
);

console.log(`\nMRR at Interface Temperature: ${actualMRR.toFixed(1)} nm/min`);
console.log(`Enhancement over Reference: ${((actualMRR / baseMRR - 1) * 100).toFixed(1)}%`);

// Sensitivity analysis: How much does MRR change per degree?
console.log('\n=== Temperature Sensitivity ===');

const tempStep = 1; // 1 Kelvin
const mrr1K = calculateTemperatureCorrectedMRR(
    baseMRR,
    baseConditions.referenceTemp + tempStep,
    baseConditions.referenceTemp,
    baseConditions.activationEnergy
);

const sensitivity = ((mrr1K - baseMRR) / tempStep);

console.log(`MRR sensitivity: ${sensitivity.toFixed(2)} nm/min per °C`);
console.log(`Relative sensitivity: ${(sensitivity / baseMRR * 100).toFixed(2)}% per °C`);

Key Concepts Explained

Arrhenius Equation Rate = A × exp(-Ea/RT) describes how reaction rates increase exponentially with temperature.
Activation Energy Typical values: 30-60 kJ/mol for CMP processes. Higher values mean stronger temperature dependence.
Frictional Heating Heat generation = μ × P × A × V can raise interface temperature by 5-10°C during polishing.
Temperature Control Slurry flow and platen temperature control are critical for maintaining consistent removal rates.

Customization Options

  • Vary activation energy to model different slurry chemistries
  • Include spatial temperature distribution across the wafer
  • Add transient heating effects for time-dependent analysis
  • Model temperature-controlled platen systems

Real Contact Area Calculation

▼

Calculate the actual contact area between pad and wafer using the Greenwood-Williamson model for rough surfaces. Shows how local contact pressures can be orders of magnitude higher than applied pressure.

Contact Mechanics Intermediate GW Model
JavaScript 
/**
 * Real Contact Area Calculation
 * Uses Greenwood-Williamson model for rough surface contact
 */

import { calculateRealContactArea, calculateHertzContact } from './cmp-simulator.js';

// Define pad properties (typical polyurethane polishing pad)
const padProperties = {
    roughness: 5e-6,                  // 5 μm RMS roughness
    asperityDensity: 1e10,            // 1e10 asperities/m²
    asperityRadius: 20e-6,            // 20 μm mean radius
    elasticModulus: 500e6,            // 500 MPa
    poissonRatio: 0.4                 // dimensionless
};

// Process conditions
const nominalArea = 0.01;              // 100 cm² nominal contact area
const appliedPressure = 21000;         // 3 psi in Pascal

console.log('=== Greenwood-Williamson Contact Analysis ===');
console.log('\nPad Properties:');
console.log(`  RMS Roughness: ${(padProperties.roughness * 1e6).toFixed(1)} μm`);
console.log(`  Asperity Density: ${(padProperties.asperityDensity / 1e10).toFixed(1)} × 10^10 /m²`);
console.log(`  Mean Asperity Radius: ${(padProperties.asperityRadius * 1e6).toFixed(1)} μm`);
console.log(`  Elastic Modulus: ${(padProperties.elasticModulus / 1e6).toFixed(0)} MPa`);

console.log('\nProcess Conditions:');
console.log(`  Nominal Contact Area: ${(nominalArea * 1e4).toFixed(0)} cm²`);
console.log(`  Applied Pressure: ${(appliedPressure / 1000).toFixed(1)} kPa (${(appliedPressure / 6894.76).toFixed(1)} psi)`);

// Calculate real contact area
const contactResult = calculateRealContactArea(
    nominalArea,
    appliedPressure,
    padProperties
);

console.log('\n=== Contact Analysis Results ===');
console.log(`Real Contact Area: ${(contactResult.realArea * 1e4).toFixed(3)} cm²`);
console.log(`Contact Fraction: ${(contactResult.contactFraction * 100).toFixed(3)}%`);
console.log(`Number of Contacts: ${Math.floor(contactResult.realArea * padProperties.asperityDensity)}`);

// Calculate local contact pressure
const localPressure = appliedPressure / contactResult.contactFraction;

console.log(`\nLocal Contact Pressure: ${(localPressure / 1e6).toFixed(1)} MPa`);
console.log(`Pressure Enhancement Factor: ${(localPressure / appliedPressure).toFixed(0)}x`);

// Analyze individual asperity contact (Hertz model)
console.log('\n=== Individual Asperity Contact (Hertz Model) ===');

const numContacts = contactResult.realArea * padProperties.asperityDensity;
const forcePerAsperity = (appliedPressure * nominalArea) / numContacts;

const hertzResult = calculateHertzContact(
    forcePerAsperity,
    padProperties.asperityRadius,
    { E: padProperties.elasticModulus, nu: padProperties.poissonRatio },  // Pad
    { E: 130e9, nu: 0.28 }  // Silicon wafer
);

console.log(`Force per Asperity: ${(forcePerAsperity * 1e6).toFixed(2)} μN`);
console.log(`Contact Radius: ${(hertzResult.contactRadius * 1e6).toFixed(2)} μm`);
console.log(`Contact Area: ${(hertzResult.contactArea * 1e12).toFixed(2)} μm²`);
console.log(`Maximum Hertz Pressure: ${(hertzResult.maxPressure / 1e6).toFixed(1)} MPa`);
console.log(`Penetration Depth: ${(hertzResult.penetration * 1e9).toFixed(1)} nm`);

// Pressure distribution analysis
console.log('\n=== Pressure Distribution Summary ===');
console.log(`Applied (Nominal) Pressure:     ${(appliedPressure / 1e3).toFixed(1)} kPa`);
console.log(`Average Real Contact Pressure:  ${(localPressure / 1e6).toFixed(1)} MPa`);
console.log(`Peak Hertz Pressure:            ${(hertzResult.maxPressure / 1e6).toFixed(1)} MPa`);

// Compare to material yield strength
const copperYieldStrength = 70e6; // 70 MPa for annealed copper

if (hertzResult.maxPressure > copperYieldStrength) {
    console.log('\n⚠️  WARNING: Peak pressure exceeds copper yield strength!');
    console.log(`    Plastic deformation likely at asperity contacts.`);
} else {
    console.log('\n✓ Contact pressures below yield strength (elastic regime)');
}

// Sensitivity to applied pressure
console.log('\n=== Pressure Sensitivity Analysis ===');

const pressures = [14000, 21000, 28000, 35000];

console.log('Applied (psi) | Real Area (cm²) | Contact % | Local Pressure (MPa)');
console.log('--------------|-----------------|------------|--------------------');

pressures.forEach(p => {
    const result = calculateRealContactArea(nominalArea, p, padProperties);
    const psi = (p / 6894.76).toFixed(1);
    const area = (result.realArea * 1e4).toFixed(3);
    const fraction = (result.contactFraction * 100).toFixed(3);
    const local = (p / result.contactFraction / 1e6).toFixed(1);

    console.log(`${psi.padStart(13)} | ${area.padStart(15)} | ${fraction.padStart(10)} | ${local.padStart(18)}`);
});

Customization Options

  • Modify pad properties for different pad types (hard vs. soft pads)
  • Include time-dependent pad wear effects on roughness
  • Add patterned wafer topography effects
  • Model multi-scale roughness (pad and wafer)

Copper Passivation Layer Dynamics

▼

Simulate the formation and removal of copper oxide passivation layers during CMP, demonstrating tribochemical synergy.

Tribochemistry Advanced Copper CMP
JavaScript 
// Copper passivation layer simulation
import {
    calculatePassivationRate,
    calculateSteadyStateOxideThickness,
    calculateCopperRemovalRate
} from './cmp-simulator.js';

const slurryChemistry = {
    h2o2Conc: 0.05,        // 5% H2O2
    complexerConc: 0.1,    // 0.1 M glycine
    pH: 4.5,
    temperature: 298
};

const oxideThickness = calculateSteadyStateOxideThickness(
    calculatePassivationRate(slurryChemistry.h2o2Conc, 2e-9, 298),
    1e-10,
    100e6,
    1.5
);

console.log(`Steady-state oxide thickness: ${(oxideThickness * 1e9).toFixed(1)} nm`);

const cuMRR = calculateCopperRemovalRate(21000, 1.5, slurryChemistry);
console.log(`Copper MRR: ${cuMRR.toFixed(1)} nm/min`);

Wafer Map Generation and Analysis

▼

Create and analyze 2D wafer maps from sparse measurement data using interpolation and statistical analysis.

Data Analysis Intermediate Visualization
JavaScript 
// Wafer map generation and uniformity calculation
import { interpolateWaferMap, calculateUniformity, plotWaferMap } from './cmp-simulator.js';

// Load sparse measurement data
const measurements = [
    { x: 0, y: 0, thickness: 5245 },
    { x: 50, y: 0, thickness: 5198 },
    { x: -50, y: 0, thickness: 5202 },
    { x: 0, y: 75, thickness: 5156 },
    { x: 100, y: 0, thickness: 5123 },
    // ... more measurement points
];

// Interpolate to full wafer map
const waferMap = interpolateWaferMap(measurements, 100, 'cubic');

// Calculate uniformity metrics
const uniformity = calculateUniformity(
    measurements.map(m => m.thickness),
    'wiwnu'
);

console.log(`WIWNU: ${uniformity.uniformity.toFixed(2)}%`);
console.log(`Mean thickness: ${uniformity.mean.toFixed(1)} Å`);
console.log(`Range: ${uniformity.min.toFixed(1)} - ${uniformity.max.toFixed(1)} Å`);

// Render wafer map
plotWaferMap(waferMap, document.getElementById('canvas'), 'viridis', {
    showScale: true,
    title: 'Post-CMP Thickness Uniformity'
});
