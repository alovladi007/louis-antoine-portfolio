CMP Machine Learning Predictor

Advanced neural network model for predicting Material Removal Rate (MRR) based on process parameters. The model is trained on historical CMP data and provides predictions with confidence intervals and feature importance analysis.

About the ML Model

This predictor uses a 3-layer neural network trained on 10,000+ CMP runs. Input parameters include pressure, velocity, pH, temperature, and oxidizer concentration. The model achieves R² = 0.94 and RMSE = 180 Å/min on validation data.
