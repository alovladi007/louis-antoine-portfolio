Published Research

Virtual Metrology for Advanced Process Control in Semiconductor Manufacturing
L. Antoine, M. Smith, J. Chen, A. Kumar
IEEE Transactions on Semiconductor Manufacturing, 2024
This paper presents a comprehensive virtual metrology framework using CatBoost machine learning algorithms for predicting critical dimensions (CD) and overlay in semiconductor manufacturing. The proposed approach achieves 94.2% accuracy in CD prediction and 91.8% accuracy in overlay prediction, significantly reducing metrology sampling requirements while maintaining process control quality. The framework includes conformal prediction for uncertainty quantification and real-time adaptation capabilities.

Run-to-Run Control with Double-EWMA and Kalman Filtering for Semiconductor Process Optimization
L. Antoine, R. Johnson, S. Lee
Journal of Process Control, 2024
We present a novel run-to-run control strategy combining double exponentially weighted moving average (Double-EWMA) with Kalman filtering for semiconductor process control. The hybrid approach provides robust control performance with 42% reduction in CD 3σ variation and 53% improvement in overlay error. The method includes constraint handling, feed-forward control, and adaptive parameter tuning for optimal performance across different process conditions.

Statistical Process Control and Fault Detection for Advanced Semiconductor Manufacturing
L. Antoine, K. Wang, T. Brown
Computers & Chemical Engineering, 2024
This work introduces an advanced statistical process control (SPC) and fault detection and classification (FDC) system for semiconductor manufacturing. The system uses Hotelling's T² and squared prediction error (SPE) charts for multivariate monitoring, achieving 96.5% fault detection accuracy with minimal false alarms. The approach includes real-time monitoring, automated alarm systems, and root cause analysis capabilities.

Multi-Objective Process Optimization for Semiconductor Manufacturing Using Genetic Algorithms
L. Antoine, D. Garcia, P. Kim
Applied Soft Computing, 2024
We present a multi-objective optimization framework for semiconductor process control using genetic algorithms. The approach simultaneously optimizes CD uniformity, overlay control, and metrology sampling reduction, providing Pareto-optimal solutions for process engineers. The method achieves 91% first-pass yield improvement and 1.71 process capability (Cpk) enhancement through intelligent parameter optimization and constraint handling.

Conformal Prediction for Uncertainty Quantification in Virtual Metrology
L. Antoine, M. Zhang, H. Patel
Machine Learning, 2024
This paper addresses uncertainty quantification in virtual metrology using conformal prediction methods. The approach provides reliable prediction intervals for CD and overlay predictions, enabling better decision-making in process control. The method achieves 95% coverage probability with tight prediction intervals, significantly improving the reliability of virtual metrology predictions in production environments.

Real-Time Process Monitoring and Control in Semiconductor Manufacturing: A Comprehensive Framework
L. Antoine, S. Wilson, A. Rodriguez, J. Liu
IEEE Transactions on Automation Science and Engineering, 2024
This comprehensive paper presents the complete Cross-Fab framework integrating virtual metrology, run-to-run control, SPC/FDC, and process optimization. The system provides real-time monitoring and control capabilities for semiconductor manufacturing, achieving significant improvements in process quality, yield, and efficiency. The framework includes REST API integration, web-based dashboards, and machine learning model management for production deployment.
