Self-Driving Vision Module

Advanced Computer Vision for Autonomous Vehicles

Project Overview

This advanced computer vision system implements real-time lane detection, object tracking, and collision prediction using deep convolutional neural networks and sensor fusion techniques. Built for autonomous vehicle navigation and safety applications.

Key Features

  • Real-time Lane Detection: Advanced edge detection and Hough transform algorithms
  • Object Tracking: YOLO v8 with DeepSORT for multi-object tracking
  • Collision Prediction: Trajectory analysis and time-to-collision estimation
  • Sensor Fusion: Combines camera, LiDAR, and radar data using Kalman filtering
  • Weather Adaptation: Robust performance in rain, fog, and night conditions

Technology Stack

OpenCV Python PyTorch YOLO v8 DeepSORT TensorRT ROS2 Kalman Filters
